Private by default

Prompts and code stay on your Mac. A server configured outside this computer is clearly flagged, and API keys live in the Keychain.

You stay in control

The agent reads freely. Every file change shows its diff first, every risky command waits for you, and ⌘. stops everything.

Made for local models

Honest context sizes, tool calls validated before they run, summaries when a session grows, and errors that say what to do next.

  • swift testRuns · safe
  • git statusRuns · read-only
  • npm install stripeAsks you first
  • rm -rf ~/Blocked
Commands

A command policy you can read.

Read-only and test commands run on their own. Anything that changes your system asks first, and dangerous commands are refused. Always allow a command in one project when you trust it.

Tools never leave the project folder, symlinks included. The model's output is treated as untrusted input, always.

Change review

Every change, reviewed before it lands.

See the diff before you allow an edit. Afterwards, the Changes tab lists everything the agent touched, side by side like a code review: keep it or revert it, file by file or all at once.

  • ✓Allow once, for the session, or deny
  • ✓Unified or split diffs with syntax colors
  • ✓Reviewable even after a relaunch

Long sessions

Sessions that remember where they started.

Local models have small contexts. When a conversation fills up, the model summarizes its beginning instead of forgetting it, and you can compact a session yourself at any time. The context meter always shows where you stand.

Compact session

From question to reviewed change.

Four steps, all on your Mac.

  1. 01

    Open a project

    Pick a folder. The agent follows its AGENTS.md and your own instructions.

  2. 02

    Choose a model

    Ollama and LM Studio models appear on their own; add any OpenAI-compatible server.

  3. 03

    Ask

    Describe the task, attach files. Follow its reasoning and tools as they stream.

  4. 04

    Approve and review

    Allow each change after seeing its diff, then keep or revert it in Changes.

Native

A real Mac app, keyboard first.

SwiftUI, light and dark mode, a command palette, notifications when the agent needs you, VoiceOver labels and Reduce Motion respected. Your sessions are saved across launches.
